```
- frames
    - c1s1_000151.jpg

    - ...
- nlpPS_descritpions.json
```
frames: contains 11816 frames of the PRW dataset.
nlpPS_descritpions.json: Contains the descriptions, bounding box and id of the person in each frame.

- Dataset split
  - Train set: person id 286-933 
  - Val set: person id 1-147 
  - Test set: person id 148-285
